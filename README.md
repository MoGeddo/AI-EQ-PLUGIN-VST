# AEQ Standard — AI EQ / VST3

دراسة قياسية لصوت غنائي في 13 ميكس مصري/عربي، ومنها بناء **بلجِن VST3** يطلّع الصوت
نفس البصمة — بمنهج قابل للقياس، مش صندوق أسود.

A measurement-driven study of a 13-song vocal corpus, and the VST3 built on it.

## التنزيل (ويندوز)

**[أحدث إصدار — Releases](https://github.com/MoGeddo/AI-EQ-PLUGIN-VST/releases/latest)**
→ نزّل `AEQ_Restore_Setup_<version>.exe` → دوس **Next → Next → Install**.

كل إصدار بيتنشر لوحده مع قائمة اللي اتغيّر + بصمة `SHA-256`. النسخة مش موقّعة
بشهادة، فويندوز هيقول «Unknown publisher» → **More info → Run anyway** (شرح كامل في
`docs/12_INSTALLER_AR.md` §8).

## ليه المشروع ده مختلف

معظم «AI EQ» بيتعلم متوسط منحنيات من أغاني مخلوطة. القياس في الريبو ده بيوضح إن
**«لمعان» الصوت مرتبط بدرجة صوت المغني بمعامل r = +0.81** — يعني الموديل بيتعلم
فسيولوجيا الحنجرة، مش قرارات المهندس.

فالمشروع هنا بيبدأ بـ:
1. **فصل تأثير الصوت** (register model) قبل أي استنتاج عن الميكس.
2. **منحنى هدف إحصائي** بفترة ثقة، مش رقم واحد مبهّم.
3. **محاور ذوق** (PCA) تتحوّل لمقابض في البلجِن.
4. **بوابات قبول قابلة للتشغيل** قبل كتابة أي سطر DSP.

## أهم النتائج

| القياس | القيمة |
|---|---|
| HPF | **172 Hz** (median) |
| ميل 100 Hz–8 kHz | **−3.47 dB/oct** (و r=+0.81 مع درجة الصوت) |
| ميل بعد إزالة تأثير الصوت | **−2.78 dB/oct**، والفرق بين الأغاني **±1.06** فقط |
| dip ثابت | **4.34 kHz** في **7/13** أغنية كـdip أساسي (p = 9.5e-5) |
| البصمة المشتركة | PC1 = 57.5% من التباين مقابل 10.7% بالصدفة (p = 0.0005) |
| ثبات المنحنى | ±2.67 dB لو شيلت أغنية واحدة → **prior مش قانون** |
| wet/dry | **−13.8 dB** · لون الإرسال **−5 dB @6.3k** |
| PLR / LRA | **11.8 dB / 7.5 LU** |
| side/mid | **−12.1 dB** (شبه مونو) |
| سقف القياس | **14.7 kHz** (lowpass الـMP3) |
| بصمة المهندس | أغاني نفس المهندس أقرب بـ **9.6 dB** (p = 0.020) — لكن **الشكل التفصيلي لا يتكرر** (p = 0.45) |

## بصمة مهندس الصوت (تحليل 06)

بحثت في اعتمادات الميكس/الماستر لكل أغنية في الكوربس (13/13، 11 مهندس ميكس) واختبرت الفرضية:
هل أغاني نفس المهندس بتتقارب؟

- **أيوه، بشكل ضعيف–متوسط:** 9.61 dB أقرب، p = **0.020** (Mantel، 20,000 تبديل)؛ ترتيب مجموعة
  أمير محروس **6 من 286** توليفة ثلاثية (تعداد كامل، p = 0.021).
- **بعد التحكم في طبقة الصوت:** 15.71 dB، p = **0.044**. أوطى 3 طبقات في الكوربس **غير** متقاربة (p = 0.713).
- **التقارب في الاتزان العريض فقط:** شيل متوسط المنحنى → p = 0.028؛ الميل التفصيلي → p = 0.143؛
  تشابه الشكل → p = 0.450. تقليل التباين **~50% في كل منطقة** (59/47/50/59%)، و**صفر** باند يصمد بعد FDR.

**الخلاصة:** اللي بيتكرر «وقفة» عريضة على طول الطيف، مش كيرف EQ تفصيلي. ده يبرّر تارجت ½ أوكتاف
مع منطقة ميتة 2.5 dB، ويمنع إصدار preset لمهندس من 3 أغاني.
**قصور صريح:** هاني محروس عنده صفر أغاني في الكوربس → فرضيته لم تُختبر.
التفاصيل: [`docs/06_ENGINEERS_AR.md`](docs/06_ENGINEERS_AR.md)
